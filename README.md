# MY LIFE IS SOCCER - Site Web

Un site web moderne pour une école de football à Breda, construit avec HTML5, CSS3 et JavaScript vanilla.

## 📋 Contenu

- **index.html** - Page principale du site
- **css/style.css** - Styles CSS complets et responsive
- **js/script.js** - Fonctionnalités JavaScript
- **images/** - Toutes les images du site
- **assets/** - Vidéos et ressources médias
- **formations/** - Pages détaillées des formations
- **trainers/** - Pages détaillées des entraîneurs

## 🚀 Démarrage Rapide

### Option 1 : Hébergement Local
```bash
# Clonez le repository
git clone https://github.com/votre-username/football2enjoy.git
cd football2enjoy

# Ouvrez index.html dans votre navigateur
# Ou utilisez un serveur local Python
python -m http.server 8000
# Puis accédez à http://localhost:8000
```

### Option 2 : Déploiement sur GitHub Pages
1. Créez un repository sur GitHub
2. Poussez les fichiers vers la branche `main`
3. Allez dans Settings > Pages
4. Sélectionnez `main` comme source
5. Votre site sera accessible à `https://votre-username.github.io/football2enjoy`

### Option 3 : Déploiement sur un Serveur Web
1. Connectez-vous à votre serveur FTP/SFTP
2. Uploadez tous les fichiers à la racine de votre domaine
3. Accédez à votre site via le navigateur

## 🔧 Personnalisation

### Changer les Couleurs
Modifiez les variables CSS dans `css/style.css` :
```css
:root {
  --primary: #5ba891;      /* Couleur principale */
  --secondary: #7eb3d4;    /* Couleur secondaire */
  --accent: #faf9f6;       /* Couleur d'accent */
}
```

### Ajouter des Images
1. Placez les images dans le dossier `images/`
2. Mettez à jour les références dans `index.html`

### Modifier le Contenu
Éditez directement les textes dans `index.html`
